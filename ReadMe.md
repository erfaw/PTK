   ## ▶️ How to Run
   1. Ensure you have Python installed.

   2. Clone the repository: 
      ```
      git clone https://github.com/erfaw/PTK
      ```

   3. Make Virtual Environment: 
      ```
      python -m venv .venv
      ```

      then on Git Bash: 
      ```
      source ./.venv/Scripts/activate
      ```

   4. Install dependencies: 
      ```
      pip install -r requirements.txt
      ```

   5. Run : 
      ```
      python main.py
      ```
